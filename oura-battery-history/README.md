# Oura Battery History

A personal, non-commercial utility to download and analyze my own Oura Ring battery-level history through the official Oura API.

- **Purpose:** Review historical battery level, charging state, charging cycles, and battery endurance.
- **Use:** Only by the owner of the connected Oura account.
- **Data access:** Requests the minimum necessary Oura device/ring configuration permission for battery readings.
- **Execution:** OAuth login via Oura; the downloader runs locally on the owner's own computer.
- **Storage:** Downloaded battery history is saved locally. No hosted service or analytics collection is operated by this project.

This is an independent personal tool and is not affiliated with or endorsed by Oura.
