# Privacy Policy — Oura Battery History

_Last updated: November 17, 2026_

## Scope

Oura Battery History is a personal, non-commercial tool used solely by the account owner to download their own Oura Ring battery-level history.

## Data accessed

With the user's explicit OAuth authorization, the tool requests Oura battery and ring/device configuration data necessary for reviewing battery level, charging state, and historical charge/discharge patterns. It does not intentionally request sleep, heart rate, location, or other health metrics.

## Storage and disclosure

The tool runs on the account owner's own computer. Battery records are downloaded directly from the Oura API to local files controlled by the owner. The tool does not operate a third-party server, upload battery files to an independently hosted service, sell data, or use analytics trackers. OAuth access tokens and application secrets are not deliberately written to the exported battery-history file.

The Oura service processes account authentication and API requests under Oura's own applicable privacy terms. GitHub hosts this public policy page and may process ordinary website usage according to GitHub's policies.

## Retention and security

The account owner controls the local output files and can delete them at any time. API authorization can be revoked through applicable Oura account controls. Access should be limited to the owner's own Oura account.

## Changes

If the tool's data handling changes, this policy should be updated before those changes are used.
